# Portfolio — Tino Meier

Persönliche Portfolio-Website. Stellt eine Auswahl an Projekten vor — eigene
Sachen (Nothrig, Kassensturz) und ein paar kleinere Beispielprojekte, die
unterschiedliche Skills zeigen sollen.

**[Live-Demo](https://p4r4gamer.github.io/portfolio/)**

## Stack

- HTML5, CSS3 (Grid, Custom Properties)
- Vanilla JavaScript
- Kein Build-Step, kein Framework

## Struktur

```
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── images/          Screenshots der vorgestellten Projekte
```

## Lokal starten

```bash
npx serve .
```

oder `index.html` direkt im Browser öffnen.
